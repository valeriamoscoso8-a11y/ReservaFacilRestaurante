# ReservaFacilRestaurante

ReservaFacilRestaurante es una aplicación web para gestionar reservas de mesas en un restaurante.

## Funcionalidades

- Registro de nuevas reservas.
- Visualización de reservas registradas.
- Búsqueda de reservas por cliente o teléfono.
- Edición y eliminación de reservas.
- Calendario interactivo por fechas.
- Conexión con base de datos MySQL.

## Tecnologías utilizadas

- HTML
- CSS
- JavaScript
- Node.js
- MySQL
- MySQL Workbench
